# Al&Pet Multi-Services — site vitrine

Cette première version est un prototype statique responsive en français, anglais et créole haïtien.

## Aperçu local
1. Décompressez le dossier.
2. Ouvrez `index.html` dans un navigateur.

## Avant publication
- Remplacez `CONTACT@VOTRE-DOMAINE.COM` dans `script.js` par l'adresse e-mail professionnelle officielle.
- Ajoutez le numéro WhatsApp/téléphone et l'adresse officielle si vous souhaitez les afficher.
- Vérifiez les descriptions et services réellement autorisés et disponibles.
- Vous pouvez remplacer le logo dans `assets/logo-alpet.jpeg` en conservant le même nom de fichier.

## Publication avec GitHub Pages
1. Créez un dépôt GitHub, par exemple `alpet-multiservices`.
2. Téléversez tous les fichiers et le dossier `assets`.
3. Dans le dépôt, ouvrez **Settings → Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**.
5. Choisissez `main` et `/ (root)`, puis **Save**.
6. GitHub affichera l'adresse publique du site après le déploiement.

## Limites importantes
Ce livrable est un site vitrine / prototype d'interface. L'espace client est une présentation seulement : il n'y a pas encore de comptes, base de données, tableau de bord administrateur réel, historique sécurisé ni traitement de transactions. Ne demandez pas aux visiteurs d'envoyer des mots de passe, codes PIN, codes OTP, informations bancaires ou pièces d'identité via ce prototype.
Les paiements et transferts nécessitent des partenaires autorisés, une architecture backend sécurisée, des contrôles de conformité et des tests avant toute mise en production.
